# docs/

Design documents for RapidStep10: discussions, investigations, postmortems, architecture notes,
specs, and how-to guides for recurring tasks.

User-facing project info stays in the root [`README.md`](../README.md), and agent instructions
stay in [`AGENTS.md`](../AGENTS.md). Everything else goes here.

## Contents

- [`google-sheet.md`](google-sheet.md): the content spreadsheet, how to access it, and how to
  refresh the site's data from it
- [`adding-a-language.md`](adding-a-language.md): step-by-step guide to adding a new locale

## Conventions

- One topic per file, with a lowercase, hyphenated name (`postmortem-2026-10-netlify-build.md`).
- Put the date in the filename for anything tied to a point in time, such as postmortems,
  investigations and decisions.
- Link to the Fizzy card a document came from, if there is one.
- Update this index when you add a file.
